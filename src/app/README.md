# 🎨 MEZON CHANNEL APP / MINI-APP (`src/app/`)

Thư mục này dành cho Giao diện Web được nhúng trực tiếp vào Channel Mezon (Iframe / Embedded Webview) hoặc Dashboard quản trị Clan.

### Công nghệ khuyến nghị:
- **Next.js 14 / React:** Tối ưu hóa render nhanh và mượt mà.
- **TailwindCSS & Lucide Icons:** Giao diện hiện đại, chuẩn aesthetic Mezon.

### Cấu trúc khuyến nghị khi phát triển:
```
src/app/
├── components/        # Các UI Components tái sử dụng (Button, Card, Modal)
├── hooks/             # Custom React Hooks
├── pages/             # Routing hoặc App Router
└── styles/            # CSS tokens, theme & globals
```
