# 🧪 TESTING SUITE (`tests/`)

Chứa toàn bộ kịch bản kiểm thử phục vụ chuẩn đánh giá chất lượng và Security Audit của Mezon Campus Studio:
- `tests/unit/`: Kiểm thử hàm, controller, model cô lập.
- `tests/integration/`: Kiểm thử luồng tích hợp với Database & Mock Mezon Gateway.
- `tests/security/`: Kiểm thử bảo mật (XSS injection, SQL Injection, Auth bypass, Token tampering).
